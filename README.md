# 预设备忘录

世界书与预设互转、备忘录、变量检查等工具。

## 安装

### 前提

请先安装 [酒馆助手 (JS-Slash-Runner)](https://github.com/n0vi028/JS-Slash-Runner)，版本 **4.8.19+**。

### 扩展管理器安装（推荐）

1. SillyTavern → **扩展** → **Install Extension**
2. 粘贴：`https://github.com/Nancyindaeyo/PresetWorldBookTransfer`
3. 刷新页面 → 启用 **预设备忘录**

扩展由 **bootstrap 直载**
`index.js`，**不会**在酒馆助手脚本树中注册「预设备忘录」条目（直载失败时会临时回退为脚本注册）。

## 使用

- 预设管理器底部：书签图标
- 扩展菜单：**预设备忘录**

### 7.0 新建与编辑

- **预设**：进入“当前预设”，在需要的位置点击“新建”。条目先加入草稿，再点顶部“保存”写入当前预设；分组内新建会加入该分组。
- **世界书**：进入“世界书导入”并选择世界书，顶部可“新建条目”，每条旁边的铅笔可编辑。列表位置可选开头、末尾、指定条目前后；点击“保存到世界书”直接写入。
- 可编辑名称、正文、启用状态、角色、激活方式、主要关键词、概率和提示词位置等。关键词每行一个，正则使用
  `/表达式/flags`；未修改的其他参数会保留。
- 保存失败保留输入；退出未保存的表单会询问。大列表使用虚拟滚动，位置候选最多显示 50 项，搜索覆盖全部条目。

## 卸载

在扩展列表删除「预设备忘录」→ 自动移除脚本树条目并清理 DOM。

## 更新

面板内可检测 GitHub 更新；也可在扩展列表手动更新。发版前维护者需 `pnpm build:preset-memo` 并提交本目录的 `index.js`。
